# Data

## Dataset Overview

The project uses structured call center operational data for analyzing call activity, agent performance, service level, abandonment, forecasting, and answer time.

## Main Data Areas

- Call volume and call handling
- Agent activity and performance
- Service level metrics
- Abandoned calls
- Forecasted vs actual call volume
- Answer time and Average Speed of Answer (ASA)
- Daily and monthly analysis

## Data Model

The Power BI model uses a dedicated DateTable to support date filtering, monthly analysis, previous-month comparisons, and time-based calculations.

## Data Preparation

Data preparation and transformation were performed using Power Query and Power BI data modeling techniques.

## Privacy

No confidential or personally identifiable customer information is included in the published portfolio materials.
